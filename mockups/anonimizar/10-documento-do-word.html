4 · Os Words que não abrem (erro)

A tela de erro é a de hoje — "Não foi possível usar este arquivo", a frase, e o botão "Escolher outro arquivo". Só a frase muda, uma para cada caso. Os nomes de arquivo são exemplos.

só imagens
Não foi possível usar este arquivo
O relatorio-escaneado.docx não tem texto, só imagens. Salve-o como PDF pelo Word e escolha o PDF: o programa lê as imagens e você confere.
protegido por senha
Não foi possível usar este arquivo
O termo-de-outorga.docx está protegido por senha. Abra no Word, tire a senha e salve de novo, e escolha o arquivo outra vez.
.doc com o nome trocado
Não foi possível usar este arquivo
O oficio-antigo.docx é um documento do Word antigo (.doc) com o nome de .docx. Abra no Word e salve como .docx.
estragado
Não foi possível usar este arquivo
O planilha.docx não pôde ser lido como documento do Word: ele pode estar estragado ou ser outro tipo de arquivo com o nome trocado.
vazio
Não foi possível usar este arquivo
O modelo-em-branco.docx está vazio: não há texto nele.
grande demais
Não foi possível usar este arquivo
O consolidado-2026.docx é grande demais para o programa abrir com segurança.
.docm, .dotx, .doc ou planilha
Não foi possível usar este arquivo
O Anonimizar abre PDF, .docx, .md e .txt. O relatorio.docm é de outro tipo.

5 · Abrindo o Word (carregando)

Não há tela própria: como o .md de hoje, o Word abre num instante e a revisão aparece em seguida. O limite de tamanho da RN-30 é o que garante que um documento enorme não deixe a janela parada.

O que não muda
  • A revisão em si: os selos, a navegação, a lista, a dupla conferência, mascarar à mão e o salvar são os de hoje.
  • O salvar sugere relatorio-de-execucao - sem CPF.md, na pasta do Word, e a tela de "gravado" lembra que o .docx continua lá com os CPFs inteiros.
  • O Gerar OCR: continua abrindo só PDF.
