# Dados de exemplo

Esta pasta é só para massa **sintética ou irreversivelmente anonimizada** —
nunca documento real, nunca CPF de gente que existe, nem "só para testar
rápido". Arquivo commitado aqui e depois apagado continua no histórico do git
para sempre, em todo clone já feito do projeto.

**Ainda não há nenhum arquivo aqui.** Quando a primeira funcionalidade (OCR ou
anonimizador de CPF) for construída, este README passa a listar cada conjunto
de exemplo: o que é, como foi gerado e o que ele exercita — inclusive um PDF
fabricado com CPF inventado e "OCR ruim" simulado, para testar os dois módulos
sem usar nenhum documento real da CAPCF.
